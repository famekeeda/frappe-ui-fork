# 🎨 Frappe Neobrutalism UI

A comprehensive, bold UI component library for Next.js apps with neobrutalism design principles. Built on Frappe UI foundations with full data fetching capabilities for Frappe backend integration.

## ✨ Features

- 🎯 **Neobrutalism Design**: Bold borders, hard shadows, and high contrast
- 🌈 **Vibrant Colors**: Monochrome base with poppy red, purple, blue, and yellow accents
- ⚡ **Next.js Ready**: Optimized for Next.js 14+ applications  
- 🎨 **Tailwind CSS**: Built with Tailwind for easy customization
- 📦 **Tree-shakeable**: Import only what you need
- ♿ **Accessible**: Built with Radix UI primitives
- 🔌 **Frappe Integration**: Full data fetching hooks for Frappe backend
- 🔧 **TypeScript**: Full type safety
- 📚 **25+ Components**: Comprehensive component library

## 🚀 Quick Start

\`\`\`bash
pnpm add @frappe-ui/neobrutalism
\`\`\`

See full documentation in the library for all 25+ components and 4 data fetching hooks (useResource, useCall, useDoc, useList).

## 📊 What's Included

**Form Components:** Button, Input, Textarea, Password, Select, Checkbox, Switch, Radio

**Layout Components:** Card, Divider

**Feedback Components:** Badge, Alert, Toast, Toaster, Spinner, LoadingIndicator, Progress, CircularProgress

**Overlay Components:** Dialog, Tooltip, DropdownMenu

**Navigation Components:** Tabs, Breadcrumbs

**Display Components:** Avatar, AvatarGroup

**Data Fetching Hooks:** useResource, useCall, useDoc, useList
